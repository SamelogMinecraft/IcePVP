# IcePVP - portfolio I made this repository to showcase my configurations and setups from my own server, IcePVP. I don't write custom plugins in Java yet, but I handle full technical server management and configuration. What is inside so far: * Ranks - setup for ranks, permissions, and prefixes (UltimateRanks) so everything works correctly without permission bugs. * VoiceChat - setup for Simple Voice Chat with fixed ports and network tweaks to prevent lag. I will gradually upload more files from IcePVP here, mainly Essentials, LuckPerms, and anti-cheat settings that I am currently working on.
